## 🐍 Jogo da Cobrinha  

Uma recriação clássica do jogo da cobrinha (Snake) utilizando HTML, CSS e JavaScript. Divirta-se controlando a cobra enquanto ela cresce ao comer frutas!  

## 🌐 Demonstração  
Acesse o jogo ao vivo em: [Jogo da Cobrinha](https://andre-studionerd.github.io/Cobra/)  

## 🚀 Tecnologias  
- HTML5  
- CSS3  
- JavaScript  

## 🎮 Como jogar  
- Utilize as setas do teclado para mover a cobrinha:  
  - ⬆️ Cima  
  - ⬇️ Baixo  
  - ⬅️ Esquerda  
  - ➡️ Direita  
- Coma as frutas para crescer e aumentar sua pontuação.  
- Se bater nas paredes ou no próprio corpo, o jogo termina!  

## 📥 Como rodar o projeto localmente  
1. Clone o repositório:  
    ```bash
    git clone https://github.com/Andre-StudioNerd/Cobra.git
    ```
2. Acesse o diretório do projeto:  
    ```bash
    cd Cobra
    ```
3. Abra o arquivo `index.html` no navegador.
